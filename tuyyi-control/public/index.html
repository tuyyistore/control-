Vercel Projects

Project yang tersedia untuk token Vercel.

Klik “Muat ulang” untuk mengambil project.

Deploy website

Unggah ZIP kecil melalui Vercel API. Untuk project framework besar, gunakan integrasi GitHub.

Catatan sebelum deploy

Deployment ZIP langsung cocok untuk file statis sederhana. ZIP dibatasi 3 MB setelah diekstrak. Project Nuxt, Next.js, Vite, atau aplikasi yang perlu proses build sebaiknya dihubungkan ke GitHub lalu di-deploy melalui integrasi Vercel. Token Vercel hanya digunakan di server.

Info DNS
